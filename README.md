# Weather App

## Project Description

This application displays real-time weather information for a selected city using the OpenWeatherMap API.

GitHub Repository:
https://github.com/deliamovila/weather-app

Frontend Live Demo (Vercel):
https://weather-app-eight-dun-65.vercel.app

Backend API (Render):
https://weather-app-howi.onrender.com

The project was developed using:
- Node.js
- Express.js
- React.js
- Vite
- Tailwind CSS

The application allows users to:
- Search for a city
- View current temperature
- View humidity
- View wind speed and direction
- View sunrise and sunset hours
- Receive clothing/weather advice

---

## Features

- Current weather data
- Celsius and Fahrenheit temperature
- Humidity information
- Wind speed and direction
- Sunrise and sunset display
- Weather advice system
- Responsive UI
- Backend API integration
- Automated tests using Jest
- UML documentation
