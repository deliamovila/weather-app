# Weather App

A modern weather web application built with React, Node.js and OpenWeather API.

---

## Features

- Search weather by city
- Temperature in Celsius and Fahrenheit
- Weather advice
- Humidity and wind direction
- Sunrise and sunset display
- Responsive design
- Error handling
- Jest testing

---

## Technologies Used

### Frontend
- React
- Tailwind CSS
- Axios
- Vite

### Backend
- Node.js
- Express
- OpenWeather API
